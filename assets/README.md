# Créditos e proveniência dos assets

## Tipografia

- Bagel Fat One Regular — família de exibição. Arquivo local fornecido no projeto Gina do usuário; preservado sem modificação. Licença SIL Open Font License 1.1: `fonts/OFL-Bagel-Fat-One.txt`.
- Onest Variable — textos e interface. Arquivo local fornecido no projeto Gina do usuário; preservado sem modificação. Licença SIL Open Font License 1.1: `fonts/OFL-Onest.txt`.

As fontes foram copiadas para este estudo e não carregam a paleta, o logotipo ou os demais elementos visuais da Gina.

## Ilustrações e texturas

- `ilustracao-copa.svg` é um desenho vetorial original criado para este conceito. `ilustracao-criancas-desenhando.jpg` é uma ilustração original gerada por IA para a cena editorial; não é registro de atividade da ONG nem retrato de crianças reais.
- `ilustracao-raizes.svg` é um estudo vetorial anterior, mantido como arquivo de processo e não usado na home atual.
- `textura-bosque.svg` é um padrão vetorial original inspirado nas referências de textura fornecidas; imagens de referência com marca d’água não foram usadas.
- `textura-escamas.svg` é um padrão vetorial original, criado a partir de formas de escamas e sem incorporar a imagem de referência com marca d’água.

## Mascote

`mascote-semente-curiosa.svg` é uma ilustração vetorial original deste conceito, criada para permanecer editável. É uma hipótese de identidade, não uma personagem oficial da organização.

## Ilustração floral

- `flor-girassol-conceitual.svg` é um grafismo vetorial original para a faixa de encerramento. Retoma a ideia de flores solares anotada no rascunho do VectorCraft, sem copiar uma peça de referência. O movimento visual da página é sutil, acionado por hover/foco e respeita a preferência por movimento reduzido.
