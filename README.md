# ViraFolha · conceito visual

Homepage demonstrativa responsiva para conversa inicial sobre identidade, site, CRM e relacionamento para uma organização ligada à natureza.

Este conceito não representa um site oficial nem confirma programas ou serviços da organização. Newsletter, CRM, email e SMS são exemplos visuais sem coleta ou envio de dados.

As ilustrações e a mascote são estudos visuais, não registros de atividades da organização. A cena editorial de crianças desenhando é uma ilustração gerada por IA; a textura de escamas é um grafismo vetorial autoral, sem uso da referência com marca d’água. Bagel Fat One e Onest são distribuídas sob SIL Open Font License; os arquivos de licença estão em `assets/fonts/`.
